# OpenCode plugin

[`context-manager/`](context-manager/README.md) contains the user's selected
**v003** context manager for **OpenCode 1.18.2**. It is a standalone local plugin:
no benchmark installation, npm dependencies, or OpenCode source checkout is needed.

The four runtime files are unchanged copies of the measured v003 snapshot.
Source paths, hashes, version selection evidence, and the upstream binary pin
are recorded in [`context-manager/PROVENANCE.json`](context-manager/PROVENANCE.json).
The OpenCode binary, credentials, experiment runners, and benchmark artifacts
are not distributed here.
