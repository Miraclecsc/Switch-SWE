And here, The default of `93` was chosen by experimenting with Jupyter Notebook. If I set it too high, it will scroll, too low and it wastes horizontal space. 93 was a compromise that fitted well on a mid-sized screen at the time. The issue with using `COLUMNS` and `LINES` is that those env vars effect the terminal. You may not want to have the same value for used both terminal and notebook. Perhaps a dedicate `JUPYTER_COLUMNS` env var to target Jupyter specifically?
