In the checkout at /work/w04, Drop overloaded usage of 'verify' and 'cert'. This PR follows up on #3022, and... * Drops the overloaded style of `verify=str`, in favor of the existing `.load_verify_locations(...)` API. * Drops the `cert` parameter, in favor of the existing `.load_cert_chain(...)` API. * Simplifies the internal `SSLContext` setup [in line with stdlib]( ). * Removes the certificate debug logging, which was odd as the single debug case in `httpx` and which is defunct now that we're using a more explicit style. At this point we have a simple `httpx.SSLContext(verify: bool)` API, with an uncomplicated implementation.
