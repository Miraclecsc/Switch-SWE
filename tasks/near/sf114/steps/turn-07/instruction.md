Please check this too: ENH: Add is_perfect_graph using SPGT (follow-up to #8111) Implements is_perfect_graph(G) based on the Strong Perfect Graph Theorem (SPGT). The function returns True if and only if neither the graph nor its complement contains an induced odd chordless cycle (odd hole) of length ≥ 5. This refines and completes the earlier proposal in [#8111]( ). The current implementation runs in exponential time in the worst case, while the full SPGT recognition algorithm is polynomial (O(n⁹)) but too intricate to include here.
