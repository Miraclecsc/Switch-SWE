One more thing: @dschult About the Big Picture This function is about finding faces of a graph when the embedding is planar. To put it in context: there are three cases actually. The number of faces of a graph depends on the embedding. Embedding can be planar or non-planar. And if it is non-planar, the manifold onto which the graph is embedded can be either orientable or non-orientable. (If it is planar, it is orientable, as all planes in \mathbb{R}^2 are orientable, so we end up with three cases.) The math here involves rotation systems (I see the Wikipedia page for it was posted). Rotation systems are a standard textbook topic. This is not research-level. Also, rotation systems can be used to find the faces in any of the three cases. This function is for the case when the graph is embedded onto a plane. It is short because embedding.neighbors_cw_order(u) gives the cyclic ordering of neighbors for the vertex u, which is essentially the rotation system for that vertex. This is contained in PlanarEmbedding. To answer @rossbar : this is not boilerplate. We need to make sure that the object is there. It is where the rotation system comes from. How I see it being used Actually, I was writing the toric code, so I needed to find edges, nodes, and faces. These are elementary things for a graph. You can find nodes and edges easily, but surprisingly, there isn’t a built-in way to find the faces. I wrote three functions for the three cases: • faces_from_planar_embedding – for the planar case • faces_from_rotation – for when a graph is embedded onto an orientable manifold. The function is called this way because it requires the user to input the rotation system. • faces_from_signed_rotation – for when a graph is embedded onto a non-orientable manifold. Here, the user inputs not only the rotation system (which won’t be enough) but also the twist. I uploaded the planar case only because my understanding is that the others could be out of the scope of that type, but I have a wrapper that computes faces, whichever case it might be.
