I have this in /work/w02: Add DAG antichain width This adds 'dag_antichain_width' which returns the size of a maximum antichain in a directed acyclic graph. The implementation uses Dilworth's theorem, the width of the partial order represented by the DAG is computed from a maximum bipartite matching on its transitive closure. This gives a polynomial-time way to compute the width of a DAG. Tests cover chains, independent nodes, a diamond-shaped DAG, and invalid inputs.
