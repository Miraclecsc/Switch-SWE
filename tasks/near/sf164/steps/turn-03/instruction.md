For the checkout at /work/w00, Mark http_exception as async to prevent thread creation. # Summary In we check if the exception_handler is an async function and if not we execute it in a different thread. This is meant to ensure that long-running sync IO operations don't block the main async eventloop. However, in the case of [http_exception]( ), a simple function that does not do any io at all the aforementioned logic spawns a thread to run the function. Marking this function async is a simple way of making sure this function does not accidently cause a thread to be created.
