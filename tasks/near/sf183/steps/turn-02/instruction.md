For the checkout at /work/w03, tags: Separate versions with multidigit components with '_' [PEP 425]( defines the version string used in Python implementation tags as follows: > The version is *py_version_nodot*. CPython gets away with no dot, but if one is needed the underscore _ is used instead. I take this to mean that, starting with Python 3.10, Python implementation tags will be of the form `cp3_10` instead of `cp310`. This PR thus updates `tags.py` to insert underscores in version strings in tags whenever one or more of the version's components are at least 10. **Note:** I am assuming that the sysconfig var `py_version_nodot` will be updated to use an underscore when Python 3.10 is released; if it is not, then the definition of `interpreter_version()` will have to be changed to use something other than `py_version_nodot`.
