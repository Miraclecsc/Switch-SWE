Currently `__le__` returns `False` unconditionally for `InfinityType`, and `__gt__` returns `True` unconditionally — neither accounts for self-comparison. The same pattern affects `NegativeInfinityType` for `__lt__` and `__ge__`. Note that `__eq__` already handles this correctly using `isinstance(other, self.__class__)`.
