I have this in /work/w01: The compatibility selector API needs an explicit public contract. Add packaging.tags.create_compatible_tags_selector(supported_tags), returning a reusable callable. This is a new selector API, not a request to rename or change the output ordering of compatible_tags() or sys_tags().

supported_tags is an ordered iterable of Tag objects, most preferred first; duplicate tags use their first occurrence. The callable accepts a finite iterable of (payload, candidate_tags) pairs, where candidate_tags is a finite iterable of Tags, and returns an iterator of compatible payloads. Rank each entry by its earliest supported tag and preserve candidate input order for ties. Emit each input entry at most once; repeated/equal/unhashable payloads remain independent entries and are returned by identity. Omit incompatible entries.

Use the supported source lazily and cache the consumed prefix for later queries. Neither constructing the factory nor constructing a query may call iter() or next() on either input. A query begins work on its first next(). Empty candidate input must not touch the supported source. Once every candidate entry has been emitted, stop without reading another supported tag, so callers can use expensive or unbounded supported streams. Retain the original APIs and all existing tests. Export the factory from packaging.tags and document it. Implement and test this first stage.
