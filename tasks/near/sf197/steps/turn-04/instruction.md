In the checkout at /work/w04, add helper for unwrapping exception groups with single exception #3197 has the fairly classic case of "I have an exceptiongroup, but I know it only contains one exception, so I don't want my user to have to use `except*`". This was also encountered in trio-websocket ( and we have a long section in the docs talking about how messy this is This PR introduces a helper that can be used in #3197 and trio-websockets, and can be recommended in the docs as well as by flake8-async. There's several pitfalls around unwrapping groups, so users generally shouldn't have to do that by themselves. See and I am very open to design discussion on how exactly this helper should behave - it's largely inspired by the implementation I did in trio-websocket.
