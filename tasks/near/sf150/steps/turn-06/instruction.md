There's something to adjust in /work/w02: The isinstance check for AsyncIterable will incorrectly return True for regular iterables that happen to have an `__aiter__` method. This could cause runtime errors when the code tries to await on a non-async iterator. Consider using `hasattr(iterable, '__aiter__')` instead or checking for `collections.abc.AsyncIterable` more carefully, or reorder the logic to check for regular Iterable first.
