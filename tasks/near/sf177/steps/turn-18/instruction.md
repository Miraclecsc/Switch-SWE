One more thing: `get_data` is still present in the modern loader. `get_filename` is optional, but for the only loader that Pytest is rewriting, it *is* implemented, so I don't see why Pytest shouldn't mirror that. importlib_resources appeals to me because it provides one API for inspecting, opening, and listing folders and zip files, and is compatbile with all versions without a bunch of extra checks. The only thing it might not support is namespace packages, but since the `files` API just returns a path-like object, we can return a path-like object when detecting a namespace.
