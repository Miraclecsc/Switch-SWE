On dual-stack platforms, using `AF_INET6` should work for both families – you'd have to explicitly opt out of IPv4 with `sock.setsockopt(IPPROTO_IPV6, socket.IPV6_V6ONLY, 1)`. The only reason this might be an issue in `create_tcp_listener()` is because we iterate over the results of `getaddrinfo()` where the IPv4 and IPv6 results are distinct from each other. So a naive implementation is not going to work well outside of the test suite.
