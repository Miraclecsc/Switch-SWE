There's something to adjust in /work/w01: fix: add suggestions from #8021 and #8029 to `is_aperiodic` This PR combines some of the changes suggested in #8021 and #8029. Use `not_implemented_for` instead of checking manually (this changes the exception type but everyone seemed to agree no deprecation was necessary in the original PRs). Switch to an approach based on `bfs_labeled_edges`. I originally tried to get a working solution using `dfs_labeled_edges`, without using `nx.strongly_connected_components`, but kept finding edge cases that it wouldn't work for. I kept the BFS because it's slightly more readable; both versions are ~30% faster over 100 runs for `G = nx.complete_graph(300, create_using=nx.DiGraph)`: Several changes to tests: removed a duplicate test for the null graph, used `with pytest.raises` instead of `pytest.raises`, and added the edge cases I came up with to the "not strongly connected" tests.
