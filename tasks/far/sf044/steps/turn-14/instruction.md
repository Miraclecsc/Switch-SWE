One more thing: I was using the `gn_graph` function to generate random graphs for simulation-based inference. We started seeing self-loops in the `gn_graph` realizations. That's because the bisect call in `discrete_sequence` has a small but non-zero probability to generate an out-of-bound sample. E.g., if the cdf is `[0, 0.1, ..., 0.9999]` then there's a 1e-4 chance of generating a sample outside the support of the distribution. The numerical error is of course much smaller than 1e-4, but we've been generating on the order of 1e6 graphs with 1000 nodes each such that we occasionally run into these self-loops for kernels `lambda degree: degree ** gamma` for 32-bit precision exponents `gamma`. I think doing the normalization at the end is nice because it guarantees there are no out-of-bound samples.
