I have this in /work/w02: BUG: fix SpanningTreeIterator AttributeError when using next() directly Fixes #8563 The `partition_queue` was only being initialised inside `__iter__`, which meant calling `next()` directly on `SpanningTreeIterator` (without a for-loop, which calls `__iter__` implicitly) raised an `AttributeError`. The fix moves the queue initialisation into `__init__` so the iterator is fully operational immediately after construction. A regression test has been added to `TestSpanningTreeIterator`.
