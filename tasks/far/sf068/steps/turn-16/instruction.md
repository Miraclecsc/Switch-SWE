And here, I believe the original logic... and this logic... is incorrect. The factor of 2 (or 0.5) is wrong. From the Wikipedia article: `The division is done by (N−1)(N−2) for directed graphs (N-1)(N-2)/2 undirected graphs`. This is predicated on an assumption that when you process an undirected graph that you iterate over all of the unique vertex pairs (when computing exact BC). This can be done on an undirected graph because the shortest path from `(u,v)` is exactly reversed from the shortest path from `(v,u)`. On a directed graph that's not guaranteed. So the assumption (in computing this normalization factor) is that you've only counted the vertices on the path `(u,v)` and not counted the vertices on the path `(v,u)`. In the nx implementation of exact betweenness, there's no logic to skip computing the path `(u,v)` and the path `(v,u)`. In computing approximate betweenness we don't make that distinction either. Consequently, the factor of 2 (or 0.5) should not be included.
