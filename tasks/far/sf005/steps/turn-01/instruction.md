I have this in /work/w02: Async signals lose ContextVar state due to use of asyncio.gather "The natural way to share global, per-request state in asyncio is through contextvars. In Django, this is typically used via `asgiref.local.Local`. However, Django's async signal dispatch currently uses `asyncio.gather`, which internally creates new tasks (`asyncio.create_task`). This breaks context propagation, since each task gets its own copy of the context. As a result, it's impossible to set a global (context-based) variable inside a signal handler and have it shared with other signal handlers or parts of the same request/re
