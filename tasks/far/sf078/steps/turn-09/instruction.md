Also, While `==` is a valid Python operator, it also has special meaning when comparing versions. In particular, it allows for zero padding, so that `1`, `1.0` and `1.0.0` are all treated as equal under the version-equality check. There's also a mismatch in the behaviour when a glob is used, e.g. `1.1.*`. Under the hood, the `Version` class does overload the `__eq__` operator, but only to check equality of the underlying `_key` tuple. As such, it does not support globbing or 0-padding.
