To give a concrete example adapted from the tests: The following call should not depend on current interpreter because we explicitly pass in the Python version, ABI, and platform. If we relied, on `_get_config_var("Py_NOGIL", warn)` than we might incorrectly exclude ABI3 tags.

When threading is None and ABIs are supplied, infer free threading from every supplied ABI, not just the first: a CPython ABI spelling cp followed by digits and only d/m/u/t flags indicates free threading when those flags include t. Opaque ABI names containing t elsewhere must not suppress abi3. Consume one-shot ABI iterables once, preserve their order, and never consult the host Py_NOGIL when explicit ABIs provide the target description.
