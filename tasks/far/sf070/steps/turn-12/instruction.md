And here, It looks like ` ._dispatchable(edge_attrs={"capacity": float("inf")}, returns_graph=True)`: `edge_attrs` corresponds to the function parameter which must be present in the modified graph, but when passing `capacity` as a callable, it looks if that attribute (which is callable) is present inside the original graph or not, it could not find it, and thus construct it by default as inf. This corresponds to above (e_attr containing mapping of `my_cap` to inf). The fix is to preserve all the edge attribute by adding `preserve_edge_attribute=True` in ` ._dispatchable(edge_attrs={"capacity": float("inf")}, returns_graph=True, preserve_edge_attrs=True)`. This is required in all the modified function in this PR. I have tested it locally by adding and it passed the pytest as well dispatch.
