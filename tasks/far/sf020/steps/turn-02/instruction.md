For the checkout at /work/w00, Fix TransactWriteItems duplicate key detection with different key attribute order The check_unicity function in transact_write_items used str(dict) for comparison, which is insertion-order-dependent. This caused duplicate key detection to fail when a Put and Delete targeted the same primary key but with different attribute ordering (e.g., {pk, sk} vs {sk, pk}). Sort dictionary items before string conversion to ensure order-independent comparison, matching real AWS DynamoDB behavior. Closes #9904
