There's something to adjust in /work/w00: Add functions for parsing wheel and sdist filenames I finally got fed up of writing the same code to parse wheel and sdist filenames, so I thought it might be worth having a "standard" version. As written, the code only handles sdist filenames in the form described [in the packaging standards]( (`.tar.gz` files with the form `{name}-{version}.tar.gz`). It could be extended to handle more of the cases in use on PyPI (e.g., `.zip` format sdists) but I chose in the first instance to stick with the stricter definition that's the current de facto standard.
