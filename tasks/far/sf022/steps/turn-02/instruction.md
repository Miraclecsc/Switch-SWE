For the checkout at /work/w03, Pipes: add ManagedState and Start/Stop methods Hello ! This PR aims to support start/stop methods in the Aws Pipe. Also, I added the `ManagedState `to the `Pipe ` class to have better transitions between states. I changed the `create_pipe` response, now it responds `CREATING` instead of `RUNNING` . I took as reference batch job implementation, calling the `ManagedState.advance()` method everytime we want to access to a pipe, e.g `describe_pipe`, this ensures that the pipe is at terminal state (e.g `RUNNING/STOPPED`) when we try to access to it. I'm willing to support the `update_pipe` method if you think I'm in the right direction with this PR. Thanks!
