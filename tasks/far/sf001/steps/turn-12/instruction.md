And here, Properly support WebP in the image converter Subject: Fix mime type detection in image converter and add webp->png conversion. ### Feature or Bugfix Bugfix ### Purpose Although `_image_type_from_file` function is able to detect a WEBP header, this could not work due to wrong type of path being passed to that method function. As a result, creating a converter from `image/webp` format to e.g. `image/png` was not possible. This PR fixes it by both making it possible to have simple extension based detection of webp files, as well as fixing the code for detection based on actual binary header.
