There's something to adjust in /work/w04: Fix cost function in min_weighted_dominating_set ## Summary The greedy cost function in `min_weighted_dominating_set` divided by `len(neighborhood - dom_set)`, which only excludes nodes already in the dominating set. It should divide by the number of **uncovered** nodes that would be newly covered: `len(neighborhood & vertices)`. A node can be dominated (covered) by being adjacent to a dom_set member without being in dom_set itself. The old cost function didn't account for this, causing the algorithm to overestimate the value of nodes whose neighborhoods were already mostly dominated. **Before (buggy):** **After (fixed):** Also adds a zero-division guard for nodes whose entire neighborhood is already dominated, and updates the docstring example.
