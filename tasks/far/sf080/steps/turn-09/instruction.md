Add Version.replace_release(major=None, minor=None, micro=None), returning a new Version with the specified release components replaced. None leaves that component unchanged. Fill missing components with zero only as far as an edited component; preserve any further release components and the epoch, prerelease, postrelease, dev and local suffixes. Accept nonnegative integers, reject booleans and non-integers with TypeError and negative integers with ValueError. Never mutate the original, including after an invalid call. A no-argument call preserves the normalized version and release tuple.
