Similar things can happen where there is some canonicalisation operation and it is more efficient to canonicalise once at the end rather than after each multiply like `(a * c)) % p` rather than `(a * c) % p)) % p`. Similar behaviour happens in many places in sympy where there is an associative binary operation and an obvious n-ary algorithm (`sum`, `math.prod`) but you should not use the trivial n-ary algorithm.
