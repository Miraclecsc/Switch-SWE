Also, Refine automatic rollover to use the entire current buffer's size in bytes, not just the cursor after a write. For a positive max_size, write() and writelines() must attempt rollover iff the resulting buffer exceeds max_size; equality stays in memory. This includes retrying after an earlier allocation failure left an oversized buffer: seeking backward and writing a short replacement must attempt rollover again, retaining the replacement if it fails. After the directory is repaired such a write must succeed on disk at the correct position. Sparse binary writes count their zero-filled gap. max_size=0 disables automatic rollover, while explicit rollover still works and retains the same failure/retry guarantees.
