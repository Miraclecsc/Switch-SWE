Rewrite the docs for `get_template`, `select_template`, `get_or_select_template`, and `from_string`. Changes `environment.make_globals` to always return a `collections.ChainMap`, even if no template globals are given. The map prefers a dict of template globals and falls back to the environment globals. Changes will only modify the template dict, not the environment. Globals are still global, but changes to the template will only ever affect the template, while changes to the environment will still be reflected in all templates, even those that provide template globals.
