One more thing: The `_rank()` method ends up calling `libalgos.rank_1d`, which has exactly the same type constraints as `libalgos.is_monotonic`, I think, and so the reason it does work is that `rank()` first calls `_ensure_data` before calling the cython algo (and that will eg convert float16 to float64). So maybe we can also call that here before calling libalgos.is_monotonic instead of that fallback? (or have a `algorithms.is_monotonic` that does that, which can then be called here, mimicking `algorithms.rank`)
