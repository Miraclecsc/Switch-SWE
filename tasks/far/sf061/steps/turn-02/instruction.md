For the checkout at /work/w02, Fix exception suppression in asgi transport Bug description: If httpx client uses asgi transport with `raise_app_exceptions=False` and response is not complete, exception is still raised. This is mostly come up in tests where you want to check how your application behave in error states. But currently it works only with non-streaming responses, which is quite limiting. I propose simple fix for such non-complete responses to be able to comply with the `raise_app_exceptions=False`. Test case included.
