One more thing: What works for me when developing locally is to just run two simple commands from the Moto repo root: Start the server (in one terminal window): `python moto/server.py -H 0.0.0.0 -p 5000` Run your tests (in another terminal window): `TEST_SERVER_MODE=true pytest -sv -vv tests/test_pipes` It's also easy to just run the server command inside an IDE like PyCharm, so you have access to breakpoints and a debgger.
