One more thing: > We should also remove the subplots and fig/ax stuff. No ax=ax is needed on the function call. Unfortunately this stuff *is* necessary, but for a very indirect reason... if we don't include explicit fig/ax creation in the tests, then it is done implicitly inside the `draw_networkx_*` call. For user code this is no problem, but for the test suite it means that `plt.gca` and `plt.gcf` get populated, which breaks the scope of the unit test. These types of things often result in errors in the `pytest-randomly` runs, which catch inter-test dependencies when they're shuffled. Of course, this detail isn't documented anywhere!
