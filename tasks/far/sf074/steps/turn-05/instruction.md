In the checkout at /work/w00, WIP: Correct Identifier Tracking This branch implements correct identifier tracking through aliasing. This basically solves Jinja's oldest bug which is that it tries to trivially map identifiers onto Python scoping which cannot work because Python scoping is not expressive enough to support all of Jinja's features. This will also fix a ton of other issues and open up heavily improved includes. The main breakage this causes which is known is that code that overrides Context now needs to override `resolve_or_missing` instead of `resolve` if it wants custom resolve support.
