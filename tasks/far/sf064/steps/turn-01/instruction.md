I have this in /work/w02: Fix federation support for directives without surrounding whitespace As written, this regex requires two delimiters before a `directive @custom on FIELD` definition. In some cases (for example, when the preceding line is a comment), this causes `purge_schema_directives` to remove only the `@custom` part, leaving `directive on FIELD` which causes downstream parsing errors. The solution is to require the second delimiter only if the description is also present.
